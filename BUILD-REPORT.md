### Enquiry form webhook

The form currently shows an error if submitted (webhook URL is a placeholder). To connect it:

**Option A — n8n (recommended for preview/testing)**

1. Log in to n8n at `https://gs-mac-mini.tail54a913.ts.net:5678/`
2. Click **Import** → upload `~/little-slate-house/website/n8n-workflows/website-enquiry-handler.json`
3. Open the **Email notification** node and:
   - Add SMTP credentials (Settings → Credentials → New → SMTP)
   - Replace `PLACEHOLDER_OWNER_EMAIL` with your email address
4. Click **Activate** (toggle top-right)
5. The webhook path is `little-slate-house-enquiry`
6. For **tailnet preview**: update the `WEBHOOK_URL` in `src/components/EnquiryForm.astro`:
   ```
   const WEBHOOK_URL = 'https://gs-mac-mini.tail54a913.ts.net:5678/webhook/little-slate-house-enquiry';
   ```
7. Rebuild: `npm run build`

**Option B — form service (easier for production)**

Use Formspree (formspree.io), Netlify Forms, or EmailJS. Replace the webhook URL with the service endpoint. No n8n setup needed.

## Go-live checklist — Cloudflare Pages deployment

### Recommended deployment: Cloudflare Pages

**Do NOT self-host the public site on the Mac mini.** Use Cloudflare Pages (free tier) for:
- Global CDN (fast everywhere)
- Free HTTPS with automatic renewal
- Git-connected auto-deploy on push

### Steps

**1. Create a Cloudflare account** (if you don't have one)
- Go to cloudflare.com and sign up

**2. Connect the git repo**
- Push the `~/little-slate-house/website` folder to a **private** GitHub repo
- In Cloudflare Pages: Connect to Git → select the repo
- Build settings:
  ```
  Build command:     npm run build
  Output directory:  dist
  Node version:      18 (or 20)
  ```

**3. Set the custom domain**
- In Cloudflare Pages: Settings → Custom Domains → Add `www.littleslatehouse.co.uk` and `littleslatehouse.co.uk`
- Cloudflare will issue an SSL certificate automatically

**4. DNS cutover (do together)**
This is the step that makes the site go live. Do NOT do this until:
  - All placeholder content is filled in
  - Real photos are in place
  - The enquiry form webhook is working
  - You've reviewed the site on the Tailscale preview URL
  
DNS steps:
  1. Log in to your domain registrar (wherever `littleslatehouse.co.uk` is registered)
  2. Point the nameservers to Cloudflare (Cloudflare will give you the nameserver names)
  3. OR add CNAME records pointing `www` and `@` to the Cloudflare Pages URL
  
Cloudflare's DNS cutover guide: https://developers.cloudflare.com/pages/configuration/custom-domains/

**5. Update the n8n webhook for production**
Once the site is live publicly, the form needs a public-accessible webhook:
- Option A: Expose n8n via Cloudflare Tunnel (`cloudflared tunnel`) — n8n stays on the Mac mini, Cloudflare tunnels to it. No ports opened.
- Option B: Switch to a form service (Formspree, EmailJS)

**6. Remove the Wix site**
After the Cloudflare Pages site is verified live: in Wix, disconnect the domain. Do this AFTER, not before.

## Keeping the preview alive after restart

The preview server (`serve`) is not managed by launchd — if the Mac reboots it won't auto-restart.

**To auto-start on login** (optional — run once):
```bash
cat > ~/Library/LaunchAgents/co.littleslatehouse.preview.plist << 'EOF'
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0">
<dict>
  <key>Label</key><string>co.littleslatehouse.preview</string>
  <key>ProgramArguments</key>
  <array>
    <string>/opt/homebrew/bin/serve</string>
    <string>-l</string><string>4321</string>
    <string>/Users/g/little-slate-house/website/dist</string>
  </array>
  <key>RunAtLoad</key><true/>
  <key>KeepAlive</key><true/>
  <key>StandardOutPath</key><string>/tmp/lsh-preview.log</string>
  <key>StandardErrorPath</key><string>/tmp/lsh-preview.log</string>
</dict>
</plist>
EOF
launchctl load ~/Library/LaunchAgents/co.littleslatehouse.preview.plist
```
